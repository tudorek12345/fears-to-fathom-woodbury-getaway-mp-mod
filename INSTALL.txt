Each player needs their own valid Windows game installation.
BepInEx 5 Mono is included in the all-in-one package.

1. Extract the archive CONTENTS into the game root.
   winhttp.dll, doorstop_config.ini and BepInEx must sit beside
   Fears to Fathom - Woodbury Getaway.exe, with no extra build folder.
2. Back up a custom mod config before replacing it with the test config.
3. Launch normally and press F11. Host selects CoopHost; friend selects CoopClient.
4. Enter the host's reachable IP. Internet play requires TCP 27055 and UDP 27056
   to be reachable, through port forwarding or a virtual LAN.
5. Use the same package on both machines. F8 opens diagnostics, F10 captures
   scene state, and F12 toggles available passenger seats.

This package disables the forced Cabin test start and Steamworks test-app override.
Steam friend invites/relay are not implemented; transport is direct TCP/UDP.

Release build and snapshot/log regression checks pass. A complete two-player
story run of this build is still pending. Full save/resume, reconnect validation,
and ending/cinematic edge cases remain work to do.
